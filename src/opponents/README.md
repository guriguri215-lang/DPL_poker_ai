# opponents

P6-3 provides deterministic HARD node-lock synthesis, canonical model identity,
an independent reach-weighted true-leak extractor, and physically separated
Training/Validation/Test catalog foundations.

Each opponent config pins the content SHA-256 of a frozen equilibrium artifact.
Synthesis resolves the game and strategy through that registry and rejects any
version/content mismatch before applying node locks. Decimal leak amounts use one
non-exponent fixed-point spelling, so numerically equal vectors cannot acquire
different identities through formatting aliases.

Normal catalog access exposes only Training and Validation. A request for the
Test split fails before directory inspection. Test evaluation, immutable Test
batches, attempt ledgers, leagues, oracle best responses, and exploitation
efficiency are intentionally outside this package and this task.
